你好，我是 **Jcode**。

我关注从一个模糊的问题到可交付结果的完整过程：理解需求、梳理边界、实现功能、验证细节，再把经验沉淀为可复用的知识与工具。这里记录技术实践、项目思考和生活中值得留存的片段。

## 能力范围

- **全链路交付**：能够从业务需求、接口与数据模型出发，完成后台管理端、移动端与服务端的协作落地，并处理上线后的构建与部署。
- **Web 与移动端开发**：熟悉 Java / Spring 生态、Vue、UniApp、MySQL 等常见技术组合，重视接口契约、交互细节与实际可用性。
- **桌面工具与自动化**：使用 Python 构建桌面效率工具，也会把重复工作沉淀为脚本、流程或可复用组件。
- **LLM 编程与智能化探索**：持续尝试把大语言模型融入开发流程，用它协助分析、编码、调试、测试与知识整理，同时关注工具的真实边界。

## 我擅长的事

- **把复杂问题拆清楚**：先明确事实、约束与目标，再选择足够简单的方案，避免为了“看起来高级”而增加复杂度。
- **跨领域快速衔接**：能在前端、后端、数据、桌面端和部署之间切换，快速定位问题真正发生的位置。
- **把细节落到结果**：不止停在“代码写完”，也会关注接口一致性、页面呈现、构建结果与真实使用场景。
- **持续复盘与表达**：习惯把过程写成可回看的说明，让解决方案不仅能用，也能被理解和复用。

## 工作以外
